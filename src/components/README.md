# UI Components Directory

This directory contains reusable UI components for Swanford Academy:

* `src/components/ui/`: Atomic UI primitives (Buttons, Cards, Inputs, Badges, Modals).
* `src/components/layout/`: Structural layouts (Headers, Navigation, Sidebar, Footers).
* `src/components/feedback/`: Alert banners, Toast messages, Loaders.

**Architectural Rule:** Keep components decoupled from global context. Ensure high contrast, mobile responsiveness, and clean touch targets.
